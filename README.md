# 🦷 CariXray Model

This repository contains the trained deep learning model for **CariXray**, a dental caries (cavity) detection project using dental X-ray images.

## 📌 Description

The model is trained to identify dental caries from dental radiographs and is intended to be integrated into a web or desktop application for automated diagnosis assistance.

## 📂 Repository Contents

```
CariXray/
├── model.pth (or model.keras / model.h5 / best.pt)
├── README.md
└── ...
```

## 🧠 Model

- Task: Dental Caries Detection
- Domain: Medical Image Analysis
- Input: Dental X-ray Images
- Output: Caries Prediction

## 🚀 Usage

Load the trained model in your inference script and use it to make predictions on dental X-ray images.

## 📌 Note

This repository contains only the trained model. The training code, preprocessing pipeline, and deployment application are maintained separately.
